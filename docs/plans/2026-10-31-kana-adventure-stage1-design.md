# かな冒険クイズ 大幅改善 Stage 1 設計

## 背景と課題

現状の `KanaAdventureGame` は、10問の4択を答えるだけのゲームである。

- 間違えてもペナルティがなく、緊張感がない
- 出題が「文字→ローマ字」「ローマ字→文字」の2種類のみで、音声がない
- 難易度が固定で、年齢や習熟度に合わない
- 間違えた文字の復習がない
- 進捗が保存されない

## 全体計画（3段階）

| Stage | 内容 | 状態 |
|---|---|---|
| 1 | 難易度選択、ハート制、音声出題、苦手文字の再出題 | 本設計 |
| 2 | ワールド制（行ごとのステージ）とボス戦 | 未着手 |
| 3 | 進捗のバックエンド保存、星の評価 | 未着手 |

対象は幅広い年齢のため、難易度選択で調整する。音声は Web Speech API を使う。

## Stage 1 ゴール

難易度選択、ハート制、音声出題、苦手文字の再出題が動作する。

## 画面の流れ

```
難易度選択 → 冒険（10問） → 結果
 やさしい/ふつう/むずかしい   ハートが0で「ざんねん」
```

結果画面から「もう一度」と「難易度を変える」を選べる。

## ファイル構成（`frontend/src/components/Games/Kana/`）

- `KanaAdventureGame.jsx`: 画面遷移と全体の状態管理
- `adventureConfig.js`: 難易度ごとの設定（選択肢数、ハート数、出題タイプ）
- `questionGenerator.js`: 問題生成の純粋関数（苦手文字の重み付けを含む）
- `DifficultySelect.jsx`: 難易度選択画面
- `KanaAdventureGame.css`: ハート表示、難易度画面のスタイルを追加
- `frontend/src/utils/speech.js`: Web Speech API の薄いラッパー

## 難易度設定

| | 選択肢 | ハート | 出題タイプ |
|---|---|---|---|
| やさしい | 3 | 5 | 音→文字 |
| ふつう | 4 | 3 | 音→文字、文字→ローマ字 |
| むずかしい | 4 | 2 | ローマ字→文字、文字→ローマ字、音→文字 |

## 問題生成（`questionGenerator.js`）

- 入力: `{ chars, difficulty, weakIds }`
- 出力: `{ target, type, options }` の配列
- `type`: `sound-to-char` / `char-to-romaji` / `romaji-to-char`
- 苦手文字（`weakIds`）を優先して混ぜ、残りはランダムに選ぶ
- ダミー選択肢は重複なしを保証する（現状の `includes` による判定を改善）
- 再出題: 間違えた文字を2〜3問後ろに挿入する。1回までとし、スコアの母数には含めない

## 音声（`utils/speech.js`）

- `speechSynthesis` を使い、`lang='ja-JP'`、`rate=0.8` で読み上げる
- 問題表示時に自動で読み上げ、🔊 ボタンで再生もできる
- `isSupported()` が false の場合、または `getVoices()` に ja がない場合は、音声出題を文字出題に置き換える

## ハート制

間違えるとハートが1つ減り、0で「ざんねん」画面へ進む。

## エラー処理

- 文字データが選択肢数より少ない場合は、起動時に明確なエラーをログに出す
- 音声再生の失敗は `console.warn` で理由を残し、文字出題へ切り替える
- 例外を握りつぶさない

## テスト方針

- フロントエンドにテスト基盤がないため、Vitest を devDependency に1つ追加する（承認済み）
- テスト対象は `adventureConfig.js` と `questionGenerator.js` の純粋関数のみ
  - 選択肢に重複がなく、正解が必ず含まれる
  - 難易度ごとの選択肢数が正しい
  - 苦手文字が優先して出題される
  - 再出題が1回までで、スコアの母数に入らない
  - 音声が非対応のとき、音声出題が文字出題に置き換わる
- `speech.js` と UI はブラウザで手動確認する

## 実装手順

1. Vitest を導入し、`adventureConfig.js` と `questionGenerator.js` をテスト先行で作る
2. `speech.js` を追加し、非対応時のフォールバックを入れる
3. `DifficultySelect.jsx` を追加し、`KanaAdventureGame.jsx` を画面遷移ベースに組み替える
4. ハート表示、ざんねん画面、再出題を組み込み、CSS を整える
5. 起動して3つの難易度を手動で確認する

## 範囲外

ワールド制とボス戦（Stage 2）、進捗保存と星の評価（Stage 3）
