# メモリゲーム用画像

このディレクトリには、メモリゲームで使用するアンパンマンの画像を配置します。

## 画像ファイル名

以下の20枚の画像を配置してください：

- anpanman1.png
- anpanman2.png
- anpanman3.png
- ...
- anpanman20.png

## 画像仕様

- 推奨サイズ: 200x200px 以上
- フォーマット: PNG (透過背景推奨) または JPG
- アスペクト比: 1:1 (正方形推奨)

## 注意事項

画像が配置されていない場合、カードには絵文字と番号が表示されます（例: 🎭1）。

## 画像の入手方法

著作権に注意して、以下のいずれかの方法で画像を用意してください：

1. フリー素材サイトから入手
2. 自分で撮影またはイラストを作成
3. ライセンスを持つ正規の画像を使用
